# Paranormal Nobodies — scan walk-throughs

Browser walk-throughs of the location scans (XGRIDS PortalCam → LCC Studio → one
merged Gaussian splat per location). Live: https://cinemaas.github.io/pn-scouts/

Each page is generated by `tools/make_scout_site.py` in the pipeline repo from
`tools/scout_site_template.html`; the splats are built with PlayCanvas
splat-transform (finest LOD under ~4.5M gaussians, floaters removed, SH dropped,
written as unbundled SOG). Rendered with PlayCanvas 2.22.2.
